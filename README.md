# Ellipse Geometry Calculator

A Java-based desktop application designed to calculate various geometric properties of an ellipse, demonstrating Object-Oriented Programming (OOP) principles.

## Features
- Calculate Ellipse Area and Perimeter
- Input validation and intuitive user interface
- Implementation of OOP concepts (Inheritance, Polymorphism, Encapsulation)

## Tech Stack
- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/qolyubmir24/ellipse-geometry-calculator.git
   ```
2. Open the project in your favorite Java IDE (IntelliJ IDEA, NetBeans, Eclipse, or VS Code).
3. Run the main class file.
